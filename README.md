# Гибридная идентификация нелинейных динамических систем

В репозитории представлены код и материалы исследования гибридного подхода к идентификации нелинейных динамических систем, объединяющего нейросетевую модель состояния и расширенный фильтр Калмана (EKF).

Нейронная сеть используется как модель динамики объекта, а EKF уточняет её скрытое состояние по текущим измерениям. Исправленное состояние возвращается обратно в нейросеть и используется при дальнейшем прогнозировании.

## Цель работы

Исследовать возможность повышения точности нейросетевых моделей динамических систем с помощью коррекции их скрытого состояния расширенным фильтром Калмана.

Дополнительно исследуется адаптивное изменение ковариационных матриц шумов Q и R по методу Акхлаги — Чжоу — Хуана.

## Исследованные нейросетевые модели

В работе рассмотрены пять вариантов нейросетевой модели состояния:

- ENN — сеть Элмана;
- LSTM;
- GRU;
- TCN — временная свёрточная сеть;
- MLP с окном задержки.

Для каждой модели исследуется совместная работа с расширенным фильтром Калмана.

## Наборы данных

Эксперименты выполнены на трёх записях открытой базы DaISy:

- `96-006` — лабораторный фен;
- `99-001` — система отопления;
- `96-016` — промышленная сушилка.

Первые две задачи являются системами с одним входом и одним выходом.

Промышленная сушилка рассматривается как многоканальная система с тремя входами и тремя выходами.

Данные разделяются по времени:

- 60 % — обучение;
- 20 % — проверочная выборка;
- 20 % — тестовая выборка.

Нормализация выполняется с использованием статистик только обучающей части.

## Принцип гибридного метода

На каждом временном шаге выполняются следующие действия:

1. нейросетевая модель прогнозирует новое скрытое состояние;
2. по этому состоянию формируется прогноз выхода;
3. EKF оценивает неопределённость прогноза;
4. измерение используется для коррекции скрытого состояния;
5. скорректированное состояние передаётся в следующий шаг нейросети.

Таким образом, фильтр корректирует не только текущий выход, но и внутреннюю память модели.

## Обучение

Нейросетевые модели обучаются на последовательных фрагментах временного ряда.

Горизонт автономного прогноза постепенно увеличивается:

`8 → 16 → 32 → 64`

Для каждой архитектуры рассматриваются несколько конфигураций.

Выбор архитектуры и параметров фильтра выполняется только по проверочной выборке. Тестовая выборка используется после окончательной фиксации параметров.

## Варианты фильтра

Рассматриваются два варианта EKF.

### Статический EKF

Матрицы ковариаций модельной ошибки `Q` и измерительного шума `R` после настройки остаются постоянными.

### Адаптивный EKF

Матрицы `Q` и `R` рекурсивно изменяются на каждом временном шаге по методу Акхлаги — Чжоу — Хуана.

Параметр скорости адаптации `tau` также выбирается по проверочной выборке.

## Основные результаты

Для каждой задачи архитектура выбиралась по проверочной выборке.

| Набор данных | Выбранная сеть | RMSE сети | RMSE измерения | RMSE статического гибрида | RMSE адаптивного гибрида |
|---|---|---:|---:|---:|---:|
| 96-006, лабораторный фен | GRU | 0.09322 | 0.08525 | 0.05068 | 0.07853 |
| 99-001, система отопления | MLP | 5.30115 | 3.82452 | 1.72123 | 1.79766 |
| 96-016, промышленная сушилка | TCN | 0.85571 | 0.09112 | 0.08557 | 0.29815 |

Статический гибрид показал меньшую ошибку, чем чистая нейронная сеть, на всех трёх исследованных объектах.

Для лабораторного фена RMSE относительно чистой нейронной сети уменьшилось примерно на 45,6 %.

Для системы отопления уменьшение составило примерно 67,5 %.

Для промышленной сушилки уменьшение составило примерно 90 %.

Адаптивный вариант не дал универсального улучшения относительно статического EKF и оказался полезен только в отдельных режимах.

## Главный вывод

Наиболее существенным является не использование одной конкретной нейросетевой архитектуры, а сам принцип гибридной модели:

**нейросетевая модель состояния + коррекция скрытого состояния расширенным фильтром Калмана.**

Оптимальная нейросетевая архитектура зависит от динамики конкретного объекта.

GRU при этом показала наиболее универсальное поведение и практически не уступала лучшим архитектурам на остальных задачах.
